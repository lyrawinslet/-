# 数据与结果说明

本文件说明仓库内每个目录/文件的作用，内容与论文**附录 A 表 A-1**（辅助材料文件列表）一致。
所有路径均相对于仓库根目录。

## 1. 原始数据（`data/`）

| 文件 | 内容 |
| --- | --- |
| `附件1.xlsx` | 典型日分时电价、小区负荷与光伏功率数据（问题一） |
| `附件2.xlsx` | 评价期负荷、光伏实测与整点光伏预报数据（问题二、三） |
| `附件3.xlsx` | 波动电价数据（问题四） |
| `附件4.xlsx` | 波动电价场景下的负荷、光伏数据（问题四） |

> 数据为竞赛题目附件，版权归出题方所有，仅用于学习与复现交流。

## 2. 五份提交结果（仓库根目录）

| 文件 | 内容 | 工作表 |
| --- | --- | --- |
| `result1.xlsx` | 问题一典型日调度结果 | 计划购电量、充放电量 |
| `result2.xlsx` | 问题二固定合同调度结果 | 计划购电量、充放电量、紧急购电量 |
| `result3.xlsx` | 问题三滚动调整调度结果 | 计划购电量、调整购电量、充放电量、紧急购电量 |
| `result4-2.xlsx` | 波动电价下固定合同调度结果 | 计划购电量、充放电量、紧急购电量 |
| `result4-3.xlsx` | 波动电价下滚动调整调度结果 | 计划购电量、调整购电量、充放电量、紧急购电量 |

这五份工作簿既是提交结果，也是 `run.py` 重算时的**格式基准**：重算只写入新建输出目录，
永远不会覆盖它们。

## 3. 求解代码（`code/`）

| 文件 | 功能 |
| --- | --- |
| `run_models.py` | 组织四问计算与结果输出（正式计算入口） |
| `q1_main.py`、`q1_common.py`、`q1_baseline.py` | 求解问题一及无储能基准 |
| `q2_full_feedback.py`、`q2_common.py`、`q2_forecast_experiment.py` | 问题二预测、购电与储能实时反馈调节 |
| `q3_model.py` | 问题三逐次结算的滚动购电模型 |
| `q4_model.py` | 问题四波动电价下的两类策略及对照 |
| `export_results.py` | 按既有工作簿的表头与样式导出 Excel 结果 |
| `verify_results.py` | 不重求解、仅用标准库核对电量、储能状态与费用 |
| `verify_inheritance.py`、`run_common_soc_robustness.py` | 电价替换一致性与相同初始储电量检验 |
| `run_supplement.py` | 组织两项补充实验的计算与独立核验 |
